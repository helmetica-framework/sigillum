= Code structure

[cols="1,1",options="header"]
|===
|Path |What's there

|`api/v1`
|The `NetworkConfig` and `ExposureClass` types (`sigillum.helmetica.io/v1`): spec, status and generated deepcopy code.

|`cmd`
|The `sigillum` CLI (cobra): `root.go` wires the binary, `controller.go` is the `sigillum controller` subcommand that builds the manager and registers `NetworkConfigManager`.

|`controllers`
|`NetworkConfigManager`, the reconciler for `NetworkConfig`. `desiredPhase` writes the `NetworkPolicy`; `ingressPeers` decides who gets in.

|`controllers/gatewayapi`
|Builders and status readers for the Gateway API objects (ListenerSet, TCPRoute, Gateway), on top of the upstream `sigs.k8s.io/gateway-api` types.

|`config`
|Kustomize tree: `crd` (the CRD manifests, installed separately), `rbac`, `manager`, `default` (RBAC + manager, no CRDs) and `samples`.
|===
